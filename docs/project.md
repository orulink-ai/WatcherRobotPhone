# 项目说明

## 一句话介绍

在 48 小时内，为 WatcheRobot 增加一个手机操作助手 Application：通过语音理解用户意图、观察手机屏幕，并让 ESP32 模拟键鼠完成手机上的具体操作。

## 场景与动机

WatcheRobot 已有实体机器人形态。我们希望探索：当手机摆在机器人面前或放在未来 C2 场景中时，机器人能否从对话伙伴变成会使用手机的助手。

长远体验可以是“中午帮我选一份午饭”。本次黑客松先验证其中最核心的技术闭环，不承诺在初始化阶段完成点外卖或自动支付。

## 本次做什么

- 用户用语音或文字下达一个范围明确的手机任务。
- 手机伴随 App 获取用户授权的屏幕图像。
- 视觉模型根据当前屏幕选择下一步动作。
- Application 校验并转换动作，经设备通道交给 ESP32。
- ESP32 以标准键鼠配件身份操作手机。
- 重新观察屏幕，确认是否需要继续、结束或人工接管。

## 展示目标

现场能看到一条完整任务链：用户说出目标，机器人回应，手机执行若干步可见动作，最终停在目标页面；同时展示关键截图、动作与执行结果。

首选低复杂度任务：打开目标 App，搜索关键词，进入目标详情页。最终演示任务在目标手机与 HID 初测后确定，并在评审说明中如实更新。

## 本次边界

- 第一优先级是手机 App + ESP32，摄像头路线暂不进入关键路径。
- 采用逐步观察与执行，不预设通用手机任务已经可用。
- 截图授权、后台持续采集、配对与定位误差需要真机验证。
- 用户在本次对话中提供了巡场与京东总部参观照片的线索；图片尚未加入仓库。
