## 如何查看交互图

GitHub 文件页显示 HTML 源码。克隆仓库或下载仓库 ZIP 后，直接使用浏览器打开 `docs/dataflow.html`，无需安装依赖或配置模型密钥。

该图展示第三方参考项目的现状，不表示 WatcheRobot 已完成集成。使用步骤按钮查看数据流、协议与对应源码，点击“查看完整链路”查看整体分工。

## 研究边界

本仓库只保存调查说明、来源链接与校验清单，不包含下载的第三方固件或 App 源码。原始材料固定到公开 commit，可追溯；本次未实测其硬件行为。
